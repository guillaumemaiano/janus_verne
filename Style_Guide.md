# Style Guide

## File Naming

`README.md` is the only all-caps-named file.

All other Markdown files use Pascal_Snake_Case:

* Architecture.md
* Getting_Started.md
* Install.md
* User_Guide.md
* World_Guide.md
* Style_Guide.md

Avoid:

* ARCHITECTURE.md
* architecture.md
* getting_started.md
* GettingStarted.md

## Philosophy

Consistency is preferred over cleverness.

Conventions should minimize surprises and make repositories easy to navigate.

Exceptions should be rare and explicit.
